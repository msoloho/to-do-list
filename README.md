# to-do-list

Lockedin:
Lockedin is a productivity app I'm building for macOS using SwiftUI and SwiftData as part of Hack Club Terra! The goal is to create a simple and easy-to-use to-do list that eventually helps people stay focused and avoid procrastination by blocking distracting apps and websites. Right now, the app lets users create, delete, and complete tasks, set custom deadlines, and save their tasks automatically so they don't disappear when the app closes. I'm currently working on adding task editing, reminders, priorities, and a focus timer. Eventually, I also want to add website and app blocking, as well as synchronization with Android phones.

How to Run:
To try Lockedin, head over to the Releases section, download the latest ZIP file, unzip it, and open the application on your Mac. Since the app is still in beta and isn't signed by Apple, macOS might display a security warning.

About the Project:
I'm building Lockedin using Swift, SwiftUI, SwiftData, and Xcode. This is one of my first macOS projects, and I'm learning Swift as I go, so the app is still a work in progress.

More updates and features coming soon!
